### 🏗️ **Schema Prisma - Tablas faltantes para variantes**

Para soportar variantes, se necesitaría:

```prisma
model ProductVariant {
  id        String  @id @default(uuid())
  productId String
  sku       String  @unique
  name      String  // ej: "Talle M", "Color Rojo"
  price     Float?  // si tiene precio diferencial
  stock     Stock[]
  product   Product @relation(fields: [productId], references: [id])
}
```

**Modificaciones necesarias en Product:**
- `imageUrl String?` - URL de imagen
- `batch String?` - Lote del producto
- `expirationDate DateTime?` - Fecha de vencimiento

**Modificaciones necesarias en Branch:**
- `address String?` - Dirección
- `hours String?` - Horarios de atención
